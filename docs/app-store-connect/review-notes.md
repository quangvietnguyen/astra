## Paste-ready notes (confirm against the submitted build)

Astra is an interactive lunar visualization for iPhone and iPad. No demo account is required.

On first launch, Astra may request foreground location permission. Location is optional; if permission is denied, the app continues with a default equatorial view. When allowed, location adjusts the lunar view and location status shown in the interface.

The main screen shows a 3D Moon with phase-aware lighting and lunar information. Drag the horizontal timeline ruler to explore dates. Tap **TODAY** to return to the current date. The timeline can be expanded or collapsed. The **TIDAL LOCK** button holds the Moon's Earth-facing rotation while lighting changes with the selected date. The **SATELLITE** button shows or hides an animated artistic visualization inspired by the Lunar Reconnaissance Orbiter. Use the vertical zoom control to change the Moon's on-screen size.

The satellite animation is not live mission telemetry. Astra is an independent visualization and is not affiliated with or endorsed by NASA.
