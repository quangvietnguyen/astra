# App Store screenshots

Astra supports iPhone and iPad. Prepare real screenshots of the release candidate for both device families. Apple currently accepts one to ten `.jpeg`, `.jpg`, or `.png` screenshots; exact accepted display sizes are listed in App Store Connect's Media Manager, and the highest required resolution can scale down when the UI matches across sizes. App previews are optional. [Apple upload guidance](https://developer.apple.com/help/app-store-connect/manage-app-information/upload-app-previews-and-screenshots/)

Do not rely on the dimensions of the old mockups as a final upload specification. Select the current size shown by Media Manager for each family/orientation. Since iPad supports landscape and the layout changes in landscape, include an iPad landscape shot if Media Manager accepts it and the screenshot communicates that layout.

## Suggested shot sequence

1. **Meet the Moon** — clean 3D Moon scene with current phase information.
2. **Explore the lunar month** — expanded horizontal timeline with ruler dates and phase indicator.
3. **Tune the view** — Tidal Lock and Satellite controls with the vertical zoom control visible.
4. **See the lunar details** — compact timeline information with illumination and other displayed lunar metrics.
5. **Made for iPad** — landscape layout if it presents the iPad experience clearly; add a portrait view too if materially different.

Use genuine app UI and text legible at the display size. Do not claim real-time NASA telemetry, guaranteed astronomical accuracy, or professional navigation. Avoid personally identifying or real home location data; use denied permission or a safe test location. Do not add device frames or promotional overlays that could be confused with in-app features.
